# jumshak.rooms — сайт магазина

Красивый сайт для бренда одежды **jumshak.rooms**: каталог, корзина, избранное, оформление заказа с автоматическим переходом в WhatsApp и полноценная админ-панель.

Сделано в тёплой кремово-бежевой эстетике бренда: серифная типографика, бабочка, арка на главной, мягкие анимации.

---

## Структура проекта

```
frontend/            — сайт (можно хостить отдельно)
  index.html         — главная: hero, каталог, о бренде, доставка, отзывы, FAQ, контакты
  admin.html         — админ-панель
  css/style.css      — стиль сайта
  css/admin.css      — стиль админки
  js/config.js       — адрес backend (API_BASE)
  js/api.js          — API-клиент, получает ключ связи у backend
  js/app.js          — каталог, корзина, избранное, заказ
  js/admin.js        — логика админ-панели
  assets/img/        — фото товаров и hero

backend/             — сервер на Node.js без внешних зависимостей
  server.js          — HTTP-сервер, API, раздача frontend/
  data/db.json       — база: товары, заказы, настройки, отзывы
  uploads/           — фото, загруженные через админку
  .env               — ключ связи и пароль администратора

start.bat            — запуск в один клик (Windows)
tools/test_api.js    — 33 проверки API
```

---

## Запуск

1. Установите **Node.js 18+** (проверено на Node 24).
2. Дважды кликните **`start.bat`** — или в терминале:

```
cd backend
node server.js
```

3. Откройте:

- Сайт — **http://localhost:3000**
- Админка — **http://localhost:3000/admin**

`npm install` не нужен: у проекта нет внешних зависимостей.

---

## Вход в админку

Пароль по умолчанию: **jumshak2026** (хранится в `backend/.env`).

Сменить его можно в админке: **Настройки → Смена пароля**. Новый пароль сразу записывается в `.env`, старый перестаёт работать.

---

## Первым делом после запуска

1. **Настройки → WhatsApp-номер** — замените `996700000000` на свой номер (только цифры, с кодом страны, например `996700123456`). Пока стоит заглушка, заказы будут уходить не вам.
2. **Смените пароль администратора.**
3. Проверьте Instagram, город и строку о доставке.
4. **Товары** — поправьте ассортимент, загрузите свои фото, отметьте наличие.
5. **Отзывы** — замените демонстрационные на реальные.

## Как всё устроено

**Связь фронтенда и бэкенда — по API-ключу.** Страница при загрузке получает ключ через `GET /api/handshake` и отправляет его в заголовке `X-API-Key` с каждым запросом. Ключ и пароль лежат только в `backend/.env`; в коде и в репозитории их нет.

Ключ — это идентификатор приложения (как Firebase API key), а не пароль: он всё равно виден в браузере. Настоящая защита админки — пароль и подписанный токен сессии.

**Оформление заказа.** Клиент добавляет вещи в корзину → заполняет имя, телефон, город → `POST /api/orders`. Сервер сам пересчитывает сумму по актуальным ценам, сохраняет заказ и возвращает ссылку `wa.me` с готовым текстом заказа. Сайт автоматически открывает WhatsApp и очищает корзину.

**Статусы заказов:** новый → подтверждён → отправлен → выполнен (или отменён). Меняются в админке, клиент видит заказ в WhatsApp.

**Где данные.** Всё в `backend/data/db.json` и `backend/uploads/`. Для резервной копии достаточно скопировать эти два места.

**Фото товаров** вырезаны из ваших скриншотов Instagram; любую можно заменить в админке (кнопка загрузки фото или ссылка).

## Если фронтенд на отдельном хостинге

`frontend/` можно раздать отдельно — на Vercel, Netlify, GitHub Pages:

1. Откройте `frontend/js/config.js` и укажите `API_BASE = 'https://адрес-вашего-backend'`.
2. Backend уже отдаёт CORS-заголовки, а ключ выдаётся через handshake — менять ничего не нужно.

Сам backend лучше держать на Node-хостинге с HTTPS (Railway, Render, VPS). При смене домена не забудьте HTTPS — WhatsApp-ссылки работают и без него, но браузеры любят безопасные сайты.

## Что уже есть

- Каталог с фильтрами по категориям и поиском
- Карточка товара: состав, цвета, количество, «в корзину» и «купить сейчас»
- Корзина и избранное (сохраняются в браузере)
- Оформление заказа → сохранение в базе → автопереход в WhatsApp с текстом заказа
- Адаптивная вёрстка (телефон / планшет / десктоп)
- Админка: дашборд со статистикой и графиком за 14 дней, товары (фото, цена, наличие, «на главной»), заказы (статусы, детали, написать клиенту в WhatsApp), настройки, смена пароля
- Лимиты: 25 заказов в час с одного IP, 10 попыток входа за 10 минут
- Защита админки: пароль + подписанный токен; API — ключ связи
